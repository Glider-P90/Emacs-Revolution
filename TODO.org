  + Exemple HTML + CSS + JavaScript
    
    Ce bloc illustre un fichier HTML autonome intégrant du CSS personnalisé (défini dans <style>)
    et du JavaScript (défini dans <script>). Le CSS gère l'apparence visuelle via des variables CSS (:root)
    et des sélecteurs de classes, tandis que le JavaScript gère l'interactivité côté client.
    
    #+BEGIN_src html

      <html lang="fr">
           <head>
        <meta charset="UTF-8">
          <style>
          :root { --bg: #0a0a0f; --accent: #ff00ff; }
          .header { background: var(--bg); padding: 2rem; text-align: center; }
          .logo { font-size: 2.5rem; color: var(--accent); font-family: monospace; }
        </style>
        <script>
          document.addEventListener('DOMContentLoaded', () => {
            document.querySelector('.logo').addEventListener('click', () => {
              alert('Emacs Revolution !');
            });
          });
        </script>
      </head>
      <body>
        <div class="header">
          <h1 class="logo">Emacs Revolution</h1>
        </div>
      </body>
      </html>

    #+END_src    
  + Exemple PHP + HTML + CSS + JavaScript

    Ce bloc illustre un fichier .php où le PHP génère du HTML dynamique côté serveur,
    le CSS (inline) définit le style, et le JavaScript gère l'interactivité côté client.
    Le PHP insère des données dynamiques (variables, boucles) directement dans le HTML avant l'envoi au navigateur.
    
    #+BEGIN_src php

      <?php
        $title = "Dashboard";
        $items = ['Alpha', 'Beta', 'Gamma'];
      ?>
      <!DOCTYPE html>
      <html lang="fr">
      <head>
        <style>
          :root { --bg: #0f0f1a; --text: #e0e0e0; }
          body { background: var(--bg); color: var(--text); font-family: monospace; }
          .item { border-left: 3px solid #ff00ff; padding-left: 1rem; margin: 0.5rem 0; }
        </style>
        <script>
          function refresh() {
            fetch('/api/items')
              .then(r => r.json())
              .then(data => console.log(data));
          }
        </script>
      </head>
      <body>
        <h1><?= htmlspecialchars($title) ?></h1>
        <?php foreach ($items as $item): ?>
          <div class="item"><?= htmlspecialchars($item) ?></div>
        <?php endforeach; ?>
        <button onclick="refresh()">Rafraîchir</button>
      </body>
      </html>

    #+END_src
  + Exemple Org + HTML + CSS

    Ce bloc illustre un fichier .org où le markup Org (titres, listes, blocs de code, liens)
    est rendu côté client via un export HTML. Le CSS personnalisé (via un bloc #+BEGIN_HTML <style>)
    s'applique au rendu final. Les liens Org [[url][text]] sont convertis en balises <a href> lors de l'export.

    #+BEGIN_src org

      #+TITLE: Tutoriel
      #+OPTIONS: H:3 num:t toc:nil
      #+BEGIN_SRC org:
        <style>
          :root { --bg: #0a0a0f; --code-bg: #1a1a2e; }
          body { background: var(--bg); color: #d0d0d0; max-width: 800px; margin: 0 auto; padding: 2rem; }
          .org-code { background: var(--code-bg); padding: 1rem; border-radius: 4px; overflow-x: auto; }
          a { color: #ff00ff; text-decoration: none; }
          a:hover { text-decoration: underline; }
        </style>
      #+BEGIN_SRC

    #+END_src
