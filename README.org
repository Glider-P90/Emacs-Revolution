:project-version: 0.1

* Description
	Emacs-Revolution est une distribution modernisée d’Emacs,
	composée de paquets Lisp et d’outils complémentaires, offrant l'auto-complétion,
	détection d’erreurs, documentation, compilation, enregistrement voal, assistance IA
	etre bien plus pour un développement fluide et accessible.
