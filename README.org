** Description

Emacs-Revolution est une distribution modernisée d'Emacs 31.1.
L'objectif, empiler les paquets lisp officiel et tiers,
les plus performants et adaptés pour s'approcher d'un environnement
de développement intégré par terminal et/ou GUI le plus complet et optimisé.

Afin de permettre à ce projet d'évoluer, il y a faut une communauté entreprenante,
c'est pourquoi Emacs R. est partitionné en blocs de code source via org mode,
accompagnés de descriptions plus détaillés que le protoypage classique du code,
ayant pour attrait une plus grande accessibilté au développement du projet.

Pour le fonctionnement du projet, l'arbre des repertoires est la suivante:
+ ~/.emacs.d
  + /revolution contient tous les fichiers du projet
    + /modes contient les fichiers de configurations de chaque mode majeur lui étant associé.
  + /github contient tous les fichiers projet tiers.

Il est inutile de modifier les fichiers .el du projet lui même se trouvant
par défaut dans le répertoire ~/.emacs.d/revolution/ , ceux-ci sont générés
par [[https://orgmode.org/worg/org-contrib/babel/intro.html][Babel]] à chaque modification du code et seront écrasé par la nouvelle verions
à chaque ouverture d'emacs.

Pour plus d'information à propos du fonctionnement de [[https://orgmode.org/worg/org-contrib/babel/intro.html][Babel]],
https://orgmode.org/worg/org-contrib/babel/intro.html

** Installation

/Bash:/
#+BEGIN_SRC bash

  mkdir -p $HOME/.emacs.d/

  cp -r $PWD/.emacs.d/revolution $HOME/.emacs.d/

  cp $PWD/.emacs $HOME/

#+END_SRC

Ensuite, il suffit de lancer l'éditeur, suivre les instructions.                                                     
Une fois l'installation terminée, vous pouvez utiliser Emacs normalement.
